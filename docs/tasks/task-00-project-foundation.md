# Task 00 - Fundação e decisões iniciais

## Agente recomendado

Conversa principal.

## Objetivo

Preparar o repositório e validar as decisões antes da geração do código.

## Escopo permitido

- Verificar Git, .NET, Node, gerenciador de pacotes, Docker e Claude Code.
- Revisar os documentos existentes neste pacote.
- Registrar versões escolhidas em `docs/technical-details.md`.
- Criar `.gitignore` e `.editorconfig` adequados.
- Definir portas locais e nomes dos bancos.
- Definir comandos oficiais de build e teste.

## Fora do escopo

- Gerar APIs ou Angular.
- Instalar bibliotecas da aplicação.
- Implementar regras de negócio.

## Critérios de aceite

- Ambiente documentado.
- Decisões coerentes com os requisitos.
- Nenhum segredo versionado.
- Repositório permanece compilável no estado existente.

## Validação

- Revisar `git status` e todos os arquivos criados.
- Confirmar versões disponíveis no ambiente.
