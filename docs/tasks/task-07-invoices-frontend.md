# Task 07 - Notas no frontend

## Dependências

Tasks 03, 05 e 06 concluídas.

## Agente recomendado

`angular-frontend`

## Objetivo

Criar listagem, cadastro e detalhes de notas no Angular.

## Escopo permitido

- Cliente HTTP de Faturamento.
- Listagem com número, data e status.
- Reactive Form com `FormArray`.
- Seleção de produtos e exibição de saldo.
- Inclusão e remoção de itens.
- Bloqueio de duplicidade e quantidade inválida.
- Tela de detalhes e badge de status.

## Fora do escopo

- Botão e visualização de impressão.

## Testes automatizados

- FormArray, validações, sucesso, erro e detalhes.

## Teste manual

- Criar nota com vários produtos, recarregar, listar e abrir detalhes.
